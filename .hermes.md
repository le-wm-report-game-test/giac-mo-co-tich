# GiacMoCoTich - Godot 4.6 Project

## Verification Rule (CRITICAL)

After EVERY task or change to this project, you MUST:

1. **Run `godot_console --check-only` first** to catch compile errors:
   ```
   cd "D:\openclaw\giac-mo-co-tich" && "D:\Godot\godot_console.exe" --check-only --path "."
   ```
   Fix ALL errors and warnings before proceeding.

2. **Run Godot GUI** (`godot.exe --path "."`) to verify the game actually loads:
   ```
   cd "D:\openclaw\giac-mo-co-tich" && "D:\Godot\godot.exe" --path "."
   ```
   Watch for:
   - Crash on startup (exit code != 0)
   - Runtime errors in output (SCRIPT ERROR, Parse Error, etc.)
   - Missing resources (invalid UID, file not found)

3. **Only report task as complete** when both pass with zero errors.

### Why
- `godot_console --check-only` catches compile-time errors (type inference, missing scripts)
- `godot.exe --path` catches runtime errors that only appear when the engine actually loads the scene tree
- Some errors (invalid UIDs, missing GDExtension DLLs, circular references) only surface in GUI mode

### Godot Paths
- GUI: `D:\Godot\godot.exe`
- Console: `D:\Godot\godot_console.exe`
