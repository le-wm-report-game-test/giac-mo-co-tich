# Godot 3 → 4.7 Migration Cheatsheet

Patterns generated by LLMs that look right but are Godot 3. Replace immediately.

## Node types

| Godot 3 | Godot 4.7 |
|---|---|
| `KinematicBody` / `KinematicBody2D` / `KinematicBody3D` | `CharacterBody` / `CharacterBody2D` / `CharacterBody3D` |
| `Spatial` | `Node3D` |
| `Position2D` | `Marker2D` |
| `Position3D` | `Marker3D` |
| `Timer.start(time)` | `Timer.start(time)` (unchanged) but use `await timer.timeout` instead of `yield(timer, "timeout")` |
| `Area2D.get_overlapping_bodies()` returns `Array` | returns `Array[Node2D]` (typed) |
| `Area2D.get_overlapping_areas()` returns `Array` | returns `Array[Area2D]` (typed) |

## Movement

```gdscript
# ❌ Godot 3
func _physics_process(delta):
    velocity = move_and_slide(velocity, Vector3.UP)
    velocity.y -= gravity * delta

# ✅ Godot 4.7
func _physics_process(delta):
    velocity.y -= gravity * delta
    move_and_slide()
```

## Coroutines

```gdscript
# ❌ Godot 3
yield(get_tree().create_timer(1.0), "timeout")

# ✅ Godot 4.7
await get_tree().create_timer(1.0).timeout
```

## Signals

```gdscript
# ❌ Godot 3
connect("body_entered", self, "_on_body_entered")
emit_signal("died")
disconnect("died", self, "_on_died")
has_signal("died")

# ✅ Godot 4.7 (Callable-based)
body_entered.connect(_on_body_entered)
died.emit()
died.disconnect(_on_died)
"died" in self  # use `in` operator instead of has_signal()
```

## Annotations

| Godot 3 | Godot 4.7 |
|---|---|
| `tool` | `@tool` |
| `export var x` | `@export var x` |
| `export_range(...)` | `@export_range(...)` |
| `export_group(...)` | `@export_group(...)` |
| `onready var x = $X` | `@onready var x: Type = $X` |

## Tween

```gdscript
# ❌ Godot 3
var t = Tween.new()
add_child(t)
t.interpolate_property(self, "position", Vector2(0,0), Vector2(100,0), 1.0)
t.start()

# ✅ Godot 4.7
var t := create_tween()
t.tween_property(self, "position", Vector2(100, 0), 1.0)
```

## Random

```gdscript
# ❌ Godot 3
randi() % 100
randf() * 100

# ✅ Godot 4.7
randi_range(0, 99)
randf_range(0.0, 100.0)
```

## File I/O

```gdscript
# ❌ Godot 3
var f = File.new()
f.open("user://save.dat", File.WRITE)
f.store_string("hello")
f.close()

# ✅ Godot 4.7
var f := FileAccess.open("user://save.dat", FileAccess.WRITE)
f.store_string("hello")
f.close()
```

## `instance()` → `instantiate()`

```gdscript
# ❌ Godot 3
var p = projectile.instance()
add_child(p)

# ✅ Godot 4.7
var p := projectile.instantiate()
add_child(p)
```

## `OS` → `Time`

```gdscript
# ❌ Godot 3
var t = OS.get_ticks_msec()

# ✅ Godot 4.7
var t := Time.get_ticks_msec()
```

## Tree frame signal

```gdscript
# ❌ Godot 3
get_tree().connect("idle_frame", self, "_on_idle")

# ✅ Godot 4.7
get_tree().process_frame.connect(_on_process)
```

## Detection: quick grep

```bash
# Find any Godot 3 leakage in your project
grep -rn -E "KinematicBody|onready var|export var|yield\(|instance\(\)|interpolate_property|Tween\.new\(\)|OS\.get_ticks_msec" --include="*.gd"
```

If any match, fix before shipping.
